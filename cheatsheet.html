dp neighbor-stat 统计近邻

command

统计训练数据中每种原子的最大近邻数，用于确定 sel 参数

# PyTorch 后端
dp --pt neighbor-stat -s data -r 6.0 -t O H
# 输出 max_nbor_size: [38, 72]
# 含义：O 最多38个近邻，H 最多72个
# sel 应设为更高值（如 [46, 92]），留余量给 MD 极端构型
#deepmd#sel#neighbor-stat#近邻统计

descriptor: se_e2_a

param

最常用描述符：两体嵌入 + 角度信息（径向+角度），适合大多数体系

"descriptor": {
  "type": "se_e2_a",
  "rcut": 6.0,        // 截断半径 (Å)
  "rcut_smth": 0.5,   // 平滑截断起点 (Å)
  "sel": [46, 92],     // 每种元素最大近邻数
  "neuron": [25, 50, 100],  // 嵌入网络每层神经元
  "axis_neuron": 16,   // 轴神经元数（子矩阵维度）
  "type_one_side": true, // true=仅按邻居类型区分参数
  "resnet_dt": false,  // ResNet 时间步
  "seed": 1
}
#deepmd#descriptor#se_e2_a#参数

descriptor: se_e2_r

param

仅径向描述符：只用距离信息，不含角度，计算更快但精度稍低

"descriptor": {
  "type": "se_e2_r",
  "rcut": 6.0,
  "rcut_smth": 0.5,
  "sel": [46, 92],
  "neuron": [5, 10, 20],  // 网络比 se_e2_a 小
  "type_one_side": true,
  "resnet_dt": false,
  "seed": 1
}
#deepmd#descriptor#se_e2_r#参数

descriptor: se_e3

param

三体嵌入描述符：含键角信息，精度更高但计算量更大

"descriptor": {
  "type": "se_e3",
  "rcut": 6.0,
  "rcut_smth": 0.5,
  "sel": [40, 80],
  "neuron": [2, 4, 8],  // 三体网络更小
  "resnet_dt": false,
  "seed": 1
}
#deepmd#descriptor#se_e3#参数

描述符选择对比

param

se_e2_a(默认推荐) vs se_e2_r(快速) vs se_e3(高精度) vs hybrid(混合)：精度递增、速度递减

se_e2_a  → 两体嵌入+角度，精度好速度适中（默认选择）
se_e2_r  → 仅径向，速度快但精度低（大体系快速筛选）
se_e3    → 三体嵌入+键角，精度最高但最慢（小体系高精度）
hybrid   → 混合多种 descriptor，可设不同截断半径
#deepmd#descriptor#选择#hybrid

descriptor: hybrid 混合描述符

param

将多种 descriptor 拼接，可组合不同截断半径和类型

"descriptor": {
  "type": "hybrid",
  "list": [
    { "type": "se_e2_a", "rcut": 6.0, ... },
    { "type": "se_e2_r", "rcut": 8.0, ... }
  ]
}
#deepmd#descriptor#hybrid#混合

网络大小调优经验

param

fitting_net 缩小影响小（<5%），embedding_net 缩小影响大（50%+）

官方 benchmark (Al₂O₃ 力 RMSE eV/Å):

fitting_net 变化（embedding=[25,50,100]固定）:
[240,240,240] → 0.040
[80,80,80]   → 0.040
[20,20,20]   → 0.041
[] (线性)    → 0.054

embedding_net 变化（fitting=[240,240,240]固定）:
[25,50,100]  → 0.040
[10,20,40]   → 0.047
[4,8,16]     → 0.073
[1,2,4]      → 0.097

策略：优先保证 embedding_net 够大
#deepmd#网络大小#调优#benchmark

lcurve.out 列含义

param

训练曲线文件各列的含义和单位

列顺序:
step         训练步数
rmse_val     验证集总损失
rmse_trn     训练集总损失
rmse_e_val   验证集能量 RMSE (eV/atom)
rmse_e_trn   训练集能量 RMSE (eV/atom)
rmse_f_val   验证集力 RMSE (eV/Å)
rmse_f_trn   训练集力 RMSE (eV/Å)
lr           当前学习率

正常: loss 持续下降, val≈trn
异常: loss 震荡/跳高/不收敛
#deepmd#lcurve#训练曲线#诊断

学习率: exp 指数衰减

param

默认学习率策略，lr = start_lr × decay_rate^(step/decay_steps)

"learning_rate": {
  "type": "exp",
  "start_lr": 0.001,    // 初始学习率
  "stop_lr": 1e-6,      // 终止学习率
  "decay_steps": 5000,  // 衰减步数
  "decay_rate": 0.95,   // 衰减率（可选，自动计算）
  "smooth": false,      // true=平滑衰减，false=阶梯衰减
  "warmup_steps": 0     // 预热步数（可选）
}
#deepmd#学习率#exp#参数

学习率: cosine 余弦退火

param

余弦曲线衰减，通常比指数衰减收敛更平滑

"learning_rate": {
  "type": "cosine",
  "start_lr": 0.001,
  "stop_lr": 1e-6,
  "warmup_steps": 5000  // 预热阶段线性增加
}
#deepmd#学习率#cosine#参数

学习率: wsd 预热-稳定-衰减

param

大部分时间保持 start_lr，最后 decay_phase_ratio 比例做衰减

"learning_rate": {
  "type": "wsd",
  "start_lr": 0.001,
  "stop_lr": 1e-6,
  "decay_phase_ratio": 0.1,  // 最后10%步数做衰减
  "decay_type": "inverse_linear"  // 衰减类型：inverse_linear/cosine/linear
}
#deepmd#学习率#wsd#参数

loss 损失权重

param

能量/力/virial 损失的权重系数，随学习率线性变化

  "limit_pref_e": 1,      // 能量损失最终权重
  "start_pref_f": 1000,   // 力损失初始权重（重点学力）
