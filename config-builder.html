💡 使用提示

  • • 选中左侧 JSON 中的参数名称 → 右侧自动显示其文档说明
  • • 「✓ 校验」深度检查当前配置的语义问题；「⚡ 一键检查全部」检查 param + machine 三段 + INCAR + 跨配置一致性
  • • 「🤖 AI 提示词」生成提问提示词，复制到 matchat 问标准参数（文献/官方文档）；AI 返回后「📥 回贴答案」 粘贴回来自动解析填入
  • • 配置自动保存在浏览器本地（防抖写入），刷新页面不丢失；「🗑 重置默认」可一键恢复出厂配置
  • • machine Tab 的「⬇ 导出」会合并 train / model_devi / fp 三段为一个完整 machine.json，可直接 dpgen run 使用
  • • 确认无误后点「⬇ 导出」下载，直接覆盖到 ~/TiC_aimd_64/dpgen/ 即可使用
