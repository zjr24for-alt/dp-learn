🚀 从零训练 Cu 势函数（端到端示例）

一个最小可跑通的 DeePMD 训练闭环：环境 → 数据 → 训练 → 诊断 → 测试 → 冻结 → 使用。 按顺序执行即可，全部命令可一键复制。完整概念讲解见知识库对应文章。

1

准备环境

用 conda 创建 DeePMD-kit 环境（学习流程 CPU 版就够）。

bash
# 推荐：conda 环境（CPU 版足够学流程）
conda create -n deepmd deepmd-kit -c conda-forge

# GPU 版（按你的 CUDA 版本选择 cuda12 或 cuda11）
# conda create -n deepmd deepmd-kit libdeepmd=*=cuda12* -c conda-forge

conda activate deepmd
dp --version   # 确认安装成功

💡 遇到 conda 装不上的问题，查知识库文章《DeePMD 快速上手》或官方安装文档。

2

准备数据

把 DFT 计算（VASP OUTCAR）转成 DeePMD 训练格式。先用少量结构试跑，再扩充。

python
# 方法一：dpdata 把 VASP OUTCAR 转成 DeePMD 格式（推荐从少量结构开始）
# 安装：pip install dpdata  或  在 deepmd 环境内已自带
python << 'EOF'
import dpdata
import glob

# 把每个 OUTCAR 目录下的结构都读进来（也可以只用一个 OUTCAR 试跑）
frames = []
for f in glob.glob("OUTCAR*"):
    s = dpdata.System(f, fmt="vasp/outcar")
    frames.append(s)

data = dpdata.LabeledSystem("OUTCAR", fmt="vasp/outcar")
# 切分：80% 训练 / 20% 测试（至少留一个结构测试）
n = len(data)
train, test = data[: int(n * 0.8)], data[int(n * 0.8):]
train.to("deepmd/npy", "data/train")
test.to("deepmd/npy", "data/test")
print(f"train {len(train)} frames, test {len(test)} frames")
EOF

💡 数据是势函数精度的根本——详见知识库《dpdata 数据转换》与《数据回流：OUTCAR → set.xxx》。 生成后目录结构应为 data/train/type.raw + set.xxx/。

3

写 input.json

最小训练配置（单元素 Cu，se_e2_a 描述符）。

json
{
  "model": {
    "type_map": ["Cu"],
    "descriptor": {
      "type": "se_e2_a",
      "rcut": 6.0,
      "rcut_smth": 0.5,
      "sel": [40],
      "neuron": [25, 50, 100]
    },
    "fitting_net": {
      "neuron": [240, 240, 240]
    }
  },
  "learning_rate": {
    "type": "exp",
    "decay_steps": 5000,
    "start_lr": 0.001,
    "decay_rate": 0.95
  },
  "loss": {
    "type": "ener",
    "start_pref_e": 0.02,
    "limit_pref_e": 1,
    "start_pref_f": 1000,
    "limit_pref_f": 1,
    "start_pref_v": 0.0,
    "limit_pref_v": 0.0
  },
  "training": {
    "seed": 2026,
    "numb_steps": 400000,
    "batch_size": 4,
    "disp_freq": 1000,
    "save_freq": 10000
  }
}

💡 想可视化配置项、校验合法性？用 配置构建器。 注意 sel 需 ≥ 训练集中任意原子的最大邻居数（此处 40 为示例，偏小会报错，改大即可）。

4

训练

先跑少量步数验证流程，再跑完整训练。

bash
# 训练（GPU 上 40 万步约数小时；先跑 5000 步验证流程）
dp train input.json

# 训练过程中实时查看损失曲线：
#   打开本站工具 → 粘贴 lcurve.out → 自动诊断
#   tail -f lcurve.out

💡 训练中如何判断好不好？把 lcurve.out 粘贴进 📈 lcurve 训练诊断器，自动画曲线并诊断发散 / 过拟合 / 收敛性。判定标准详见知识库《lcurve.out 训练曲线解读》。

5

测试

用冻结前的 checkpoint 或冻结后的模型评估精度。

bash
# 测试：对测试集评估能量/力精度
dp test -m frozen_model.pb -s data/test -n 100

# 期望输出（合理水平）：
#   rmse_e  < 0.02 eV/atom
#   rmse_f  < 0.10 eV/A

💡 力 RMSE < 0.1 eV/Å 对大多数材料已可用；< 0.05 更好。不同体系阈值不同，参考论文常见水平。

6

冻结 / 压缩

把训练模型固化为单文件，便于部署与推理。

bash
# 冻结为单文件模型（推理/部署用）
dp freeze -o frozen_model.pb

# （可选）压缩，减小体积提升速度
# dp compress -i frozen_model.pb -o compress.pb
7

使用：LAMMPS / ASE

加载冻结模型做分子动力学或结构弛豫。

lammps
# LAMMPS in.lmp：加载 DP 势函数
pair_style deepmd frozen_model.pb
pair_coeff * *

# 然后正常写模拟（温度、系综等）即可
python
from deepmd.calculator import DP
from ase.io import read
from ase.optimize import BFGS

calc = DP(model="frozen_model.pb")
atoms = read("POSCAR")
atoms.calc = calc

# 结构弛豫
opt = BFGS(atoms)
opt.run(fmax=0.01)
print("能量:", atoms.get_potential_energy(), "eV")

💡 LAMMPS 集成的报错排查见知识库《LAMMPS + DeePMD 集成》；ASE 用法见《ASE 构建超胞/表面》。

8

调参循环

训练不是一次成功——看曲线、找原因、改配置、重训。

典型循环：
  1. 用 lcurve 诊断器 定位问题（发散 / 不收敛 / 过拟合 / 精度不足）
  2. 按诊断建议改配置（学习率、网络大小、数据、损失权重），参考《DeePMD 训练参数详解》与《网络大小调优》
  3. 重训后再诊断，对比两次曲线

追求更高精度或探索未知体系时，进入主动学习闭环——见知识库《DP 势函数生成完整流程》与 DP-GEN 标准流程。

⚠️ 本示例为教学用途的最小配置：单一元素、少量数据、未调优。真实研究请结合体系特性配置描述符、扩充数据并做充分验证。
