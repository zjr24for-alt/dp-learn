高熵合金建模：ATAT · SQS 特殊准随机结构

什么时候需要 SQS

体系建模方式
纯元素 / 有序化合物（TiC 等）CIF + ASE 直接建胞即可
高熵合金 / 无序固溶体ATAT mcsqs 生成 SQS 超胞
有序中间相 / 间隙固溶体由晶格+占位规则手工构造

核心判断：体系是否存在化学无序（多种元素随机占位）。只要占位无序，就需要 SQS 而不是简单替位超胞。

为什么用 SQS 而不是随机替位

随机替位的小超胞往往能量和短程有序不具代表性——几十个原子的超胞里，随机抽样的原子排布方差很大。SQS 的目标不是能量最低，而是让超胞里的短程关联函数（pair/multi-body correlation）最接近理想随机固溶体，这样小超胞也能代表宏观合金。

text
SQS 优化目标：
  匹配 pair 关联 Γ₂(R)，进而匹配多体关联 Γ₃、Γ₄...
  在给定超胞尺寸下，把关联函数误差压到目标（通常 ≤ 1e-3 量级）

mcsqs 完整流程

bash
# 1. 准备：先把目标成分写成随机占位的初始超胞（VASP/ASE 格式）
#    示例 32 原子，截断半径 10 Å
mcsqs -n 32 -rc 10.0

# 2. 迭代优化（核心），直到关联函数误差达目标
#    - 目标成分在 clust 文件中定义（mcsqs 默认读 clusters.out）
#    - 输出 sqs.out：最优结构的 POSCAR 格式
mcsqs  # 可在同一目录继续运行以延长优化

# 3. 检查关联函数匹配质量
corrdump -rnd -c > sqs_pair.out
# 对比目标关联函数，重点看前几个近邻壳层的 pair 项

# 4. 转成 VASP 用的 POSCAR
cell2vasp < sqs.out > POSCAR

# 5. 核对：原子数、化学计量比、晶格常数

mcsqs 关键参数

参数含义推荐
-n超胞原子数32~64（越大关联函数越好匹配，计算越贵）
-rc截断半径 (Å)≥ 10 Å，覆盖第一二近邻壳层
-ip每次交换的原子对数默认 1，可增大加快收敛
-sig随机种子固定后可复现

收敛判断：关联函数误差

text
目标：corrdump 输出的 pair 关联函数与理想随机值误差 ≤ 1e-3 量级
理想随机 pair 关联 Γ₂(理想) 由成分直接算：Γ₂ = Σ c_i² - 1   （A-B 二元）

判断要点：

  1. 前几个近邻壳层（第一、第二、第三 NN）的 pair 关联要准——它们决定短程有序和大多数物理性质
  2. 远壳层（> 10 Å）误差可容忍，因为长程关联影响小
  3. 多体关联（Γ₃、Γ₄）在高熵合金中也需要，但优先保证 pair 匹配

常见坑

问题解决
mcsqs 长时间不收敛增大 -n 或 -ip，或从多个随机种子重跑取最优
sqs.out 不是 POSCAR 格式用 cell2vasp 或 atomsk 转换
关联函数对不上目标成分检查 clusters.out 里成分设置是否正确
SQS 结构能量偏高正常——SQS 是"最随机的结构"不是"能量最低的结构"
命令随 ATAT 版本略有差异以你安装的 ATAT 版本 mcsqs -h 为准

与后续 DP-GEN 流程衔接

  • SQS 产出的 POSCAR 直接作为 sys_configs（init_bulk 的 from_poscar_path 或探索的初始结构）
  • 高熵合金的 type_map 元素多，记得核对 mass_map 和 fp_pp_files 顺序一一对应
  • 原子数较大的 SQS 超胞，MD 探索会偏贵——可用 super_cell: [1,1,1] 直接跑，不必再扩胞
